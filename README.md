## 아침 피팅룸 (`fitting-room/`)

아침에 옷을 입어 보고 벗는 수고를 줄이려고 만든 웹 앱이에요. 링크만 열면 폰과 PC에서 바로 쓸 수 있어요.

**바로 쓰기:** https://jianpark0617.github.io/tools/fitting-room/

- 옷 사진을 올리면 AI가 옷의 종류·모양·색을 읽고, 앱이 그 옷을 마네킹용 그림으로 그려서 입혀요. 사진 원본은 저장하지 않아요.
  - claude.ai 안에서 열면 바로 돼요. GitHub Pages 링크에서는 `fitting-room/worker/README.md`대로 분석 서버를 켜야 해요. 서버가 없으면 색만 읽고 종류와 모양은 직접 골라요.
- 체형(여성/남성), 피부색 6단계, 피부 톤(웜톤/뉴트럴/쿨톤)을 고를 수 있어요.
- "추천 코디"는 오늘 날씨, 색 조합, 옷의 분위기, 피부 톤을 따져서 조합을 골라 주고 이유도 알려 줘요.
- 마음에 드는 조합은 저장해 둘 수 있어요.
- 옷장과 설정은 각자의 브라우저에만 저장돼요. 서버로 올라가지 않고, 친구끼리도 서로의 옷장을 볼 수 없어요.

### 수정하고 다시 배포하기

`fitting-room/index.html` 한 파일이 앱 전체예요. (`fitting-room/worker/`는 사진 분석 서버 코드예요.) 이 파일을 고쳐서 `main` 브랜치에 올리면 GitHub Pages가 1~2분 안에 새 버전으로 바꿔요. 저장소 이름과 폴더가 그대로면 링크도 그대로이고, 사용자 기기에 저장된 옷장도 유지돼요.
