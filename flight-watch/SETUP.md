# ✈️ 항공권 최저가 알리미, 내 것으로 만들기 (10분)

친구가 쓰는 걸 보고 오셨다면 이 페이지만 따라 하면 돼요. 끝나면 **내 텔레그램으로, 내가 고른 여행지의 최저가**가 매일 아침 와요. 서버도, 돈도 안 들어요. 필요한 건 GitHub 계정과 텔레그램뿐이에요.

> 원리: GitHub Actions라는 무료 자동 실행 기능이 매일 아침 Google Flights를 대신 검색하고, 싸지면 텔레그램 봇이 알려 줘요. 코드는 전부 이 저장소에 있고, Fork는 "내 계정으로 복사하기"예요.

## 1. 저장소 복사하기 (Fork)

1. GitHub에 로그인한 상태로 https://github.com/jianpark0617/tools/fork 를 열어요.
2. 아무것도 바꾸지 말고 초록색 **Create fork**를 눌러요.
3. 잠시 뒤 `github.com/내아이디/tools` 주소로 내 복사본이 열려요. 앞으로는 이 주소에서 작업해요.

## 2. 자동 실행 켜기

복사본은 안전을 위해 자동 실행이 꺼진 채로 만들어져요.

1. 내 복사본 페이지 위쪽 **Actions** 탭을 눌러요.
2. "Workflows aren't being run on this forked repository" 안내가 보이면 초록색 **I understand my workflows, go ahead and enable them**을 눌러요.
3. 왼쪽 목록에서 **항공권 최저가 감시**를 누르고, 오른쪽에 **Enable workflow** 버튼이 있으면 눌러요.
4. **항공권 감시 봇 (텔레그램 명령)** 도 똑같이 눌러서 켜요.

## 3. 텔레그램 봇 만들기

1. 텔레그램에서 **@BotFather**를 검색해 열고 `/newbot`을 보내요.
2. 봇 이름(아무거나)과 아이디(영문, 끝이 `bot`)를 정하면 **토큰**을 줘요. `123456789:AAH...` 모양의 긴 문자열이에요. 복사해 두세요. 비밀번호처럼 다뤄요.
3. 방금 만든 봇을 검색해서 열고 **아무 메시지나 하나** 보내요. (봇은 먼저 말을 못 걸어서 꼭 필요해요.)
4. 브라우저 주소창에 아래를 넣어 열어요. `토큰` 자리에 2번 토큰을 넣어요.
   ```
   https://api.telegram.org/bot토큰/getUpdates
   ```
5. 나오는 글에서 `"chat":{"id":` 뒤의 숫자가 **채팅 ID**예요. `"result":[]`만 보이면 3번을 안 한 거예요.

## 4. 토큰과 채팅 ID를 저장소에 넣기

1. 내 복사본 페이지에서 **Settings → Secrets and variables → Actions**로 가요.
   주소로 바로 가려면: `https://github.com/내아이디/tools/settings/secrets/actions`
2. **New repository secret**을 눌러 아래 두 개를 하나씩 추가해요.

| Name | Secret |
|---|---|
| `TELEGRAM_BOT_TOKEN` | 3-2에서 받은 토큰 전체 |
| `TELEGRAM_CHAT_ID` | 3-5에서 찾은 숫자 |

## 5. 여행지 정하기

복사본에는 예시로 **인천 → 도쿄, 오사카**가 들어 있어요. 텔레그램 봇에게 명령을 보내서 바꾸면 돼요. 답장은 5~15분 뒤에 와요.

```
/목록                                    지금 설정 보기
/초기화                                   예시로 들어 있던 가격 기록 지우기 (처음에 한 번)
/삭제 오사카                              필요 없는 여행지 빼기
/추가 방콕 BKK 2026-12-01 2027-02-28 45만   여행지 넣기 (이름 공항 기간 기준가)
/추가 후쿠오카 ? 12-01 2-28               공항 코드를 모르면 ? 로
/기준가 도쿄 35만                          이 가격 이하면 알림
/출발지 PUS                               부산 출발이면
/요약                                     지금 최저가 바로 보기
/도움                                     명령어 전체
```

처음엔 `/초기화`를 한 번 보내 두세요. 원본 주인의 가격 기록이 남아 있어서, 지우지 않으면 "역대 최저가" 비교가 남의 기록 기준으로 돼요.

## 6. 되는지 확인

**Actions → 항공권 최저가 감시 → Run workflow**에서 `실행 방식`을 `summary`로 고르고 실행해요. 3~5분 뒤 봇한테서 최저가 요약이 오면 끝이에요. 이제 매일 아침 9시 17분에 자동으로 돌아요.

안 오면 Actions에서 그 실행을 눌러 빨간 단계의 로그를 보세요. 대개 토큰이나 채팅 ID 오타예요.

## 자주 묻는 것

- **돈 드나요?** 공개 저장소의 GitHub Actions는 무료예요. 텔레그램 봇도 무료예요.
- **원본이 업데이트되면?** 내 복사본 페이지 위쪽에 **Sync fork** 버튼이 생겨요. 누르면 새 코드를 받아요. 내 설정과 Secrets은 그대로예요.
- **알림이 왜 안 와요?** 기준가보다 비싸고 역대 최저가도 안 깨지면 조용해요. `/요약`으로 언제든 현재 가격을 볼 수 있어요.
- **`fitting-room` 폴더는 뭐예요?** 원본 주인의 다른 도구예요. 그냥 두면 돼요.
- **정확도는?** Google Flights 가격이라 실제 결제 금액과 몇천 원 차이 날 수 있어요. 메시지의 링크로 최종 가격을 확인하세요.
